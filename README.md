# BRIDGE Web UI LLM

## Input from stakeholders

- PI1 in engineering wants a reliable site with a popular stack based on JavaScript frontend and a python backend, storing results in a MongoDB nosql database. The data storage format should lend itself well for future use by LLMs, RAGs, Vector DBs, Elasticsearch and other AI agents.
- PI2 in product has a set of features about form uploading and batch processing, use of smartphones in addition to desktop browsers to upload images using the web app and results shared as from processing displayed on the screen with an option to download
- PI3 in marketing wants an attractive site that works well with a modern browser
